This talk introduces an automated solution for deploying microservices at scale by utilizing GitHub, Docker Hub and Docker Cloud. We’ll talk about the challenges, the needs and the solution from a DevOps perspective and we’ll demo such a solution where we build, run, scale and update our cloud application in an automatic fashion.

Example code repository with microservices, Docker and Docker Cloud configuration: [https://github.com/dashersw/dockercloud-microservices](https://github.com/dashersw/dockercloud-microservices)
