Web Audio API opens a new, vast world to developers and musicians. Developers can now make use of the Web Audio API to develop a new generation of music applications, from editing to creation. Pedalboard.js is the first open source library for developing real time guitar effects. Check out [pedalboard.js on github](http://t.umblr.com/redirect?z=https%3A%2F%2Fgithub.com%2Fdashersw%2Fpedalboard.js&t=MTVhNTY1ZTAxNzdlODY1ZWQ3OGQ3ODZkN2E2MWY1OGM3M2FkNWM0YixUbU4zdWpESg%3D%3D&p=&m=0). Also, [https://pedals.io](http://t.umblr.com/redirect?z=https%3A%2F%2Fpedals.io&t=ZWJlNjEyOTZhZTI5ZTUzOGU3OWFkYjA2ZTA4ZTg5MmRjMjI3ODhlMixUbU4zdWpESg%3D%3D&p=&m=0) is built on top of pedalboard.js.
