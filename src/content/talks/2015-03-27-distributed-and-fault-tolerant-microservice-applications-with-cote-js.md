Cote.js is an open-source auto-discovery mesh network framework for building fault-tolerant, highly available and scalable software at no additional cost. Cote.js allows developers to build microservices easily with various communication patterns. Example project is on [github](https://github.com/dashersw/cote-workshop). Check out cote.js [here](https://github.com/dashersw/cote).
